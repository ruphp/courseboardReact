# Учебный React + TypeScript SPA

Учебный проект для поэтапной сборки современного SPA-приложения с нуля.

## Цель

Не просто "сделать экран", а понять:

- структуру проекта
- роутинг
- страницы и модули
- общий UI
- mock API
- передачу props
- hooks
- базовую архитектуру без лишнего перегруза

## Правила проекта

- документация и пояснения ведутся на русском
- локальные служебные файлы не попадают в репозиторий
- сначала строим понятный каркас, потом усложняем
- приоритет: читаемость, простая структура, предсказуемость

## План

1. Создать каркас SPA
2. Добавить роутинг и layout
3. Подключить mock JSON и API-слой
4. Сделать список сущностей
5. Сделать страницу деталей
6. Добавить улучшения и рефакторинг

## Git-процесс

- `master` — только для релизного, стабильного состояния
- `develop` — основная рабочая ветка проекта
- каждая задача оформляется как отдельный `issue`
- под каждый `issue` создается отдельная рабочая ветка
- рабочая ветка вливается в `develop`
- в `master` попадает только проверенный релиз

### Пример схемы

1. Создаем `issue`
2. От `develop` создаем ветку задачи
3. Делаем изменения в ветке задачи
4. Вливаем задачу в `develop`
5. После набора готовых задач готовим релиз в `master`
